# ESADE Career Platform - Documentation

This directory contains all documentation for the ESADE Career Intelligence Platform.

## 📁 Directory Structure

### `/architecture`
Architecture diagrams and design documentation:
- `AWS_ARCHITECTURE_DIAGRAM_PROMPT.md` - Complete prompt for generating AWS architecture diagrams
- `ARCHITECTURE_UPDATES_SUMMARY.md` - Summary of architecture enhancements

### `/setup`
Setup guides and configuration documentation:
- `COMPLETE_SETUP_SUMMARY.md` - Complete setup summary for email verification and password reset
- `FORGOT_PASSWORD_SETUP.md` - Forgot password feature setup guide
- `USER_NOTIFICATIONS_SETUP.md` - User notification system setup
- `FRONTEND_ENHANCEMENTS.md` - Frontend enhancements documentation

### `/aws`
AWS service-specific documentation:
- `SES_PRODUCTION_ACCESS.md` - Guide for requesting SES production access
- `SES_PRODUCTION_REQUEST.md` - Step-by-step SES production access request guide
- `SES_EMAIL_RESPONSE.txt` - Ready-to-send email response for AWS SES support
- `SES_RESPONSE_TEMPLATE.md` - Template for SES support responses

### `/email`
Email-related troubleshooting and fixes:
- `EMAIL_VERIFICATION_FIX.md` - Email verification issue troubleshooting
- `QUICK_FIX_VERIFICATION.md` - Quick workaround for email verification
